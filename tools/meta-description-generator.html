Frequently asked questions

What is a meta description? +
A meta description is an HTML tag that provides a brief summary of a web page. It appears below the page title in Google search results and directly influences whether users click on your page. While meta descriptions don't directly affect rankings, a well-written one can significantly increase your click-through rate (CTR).
How long should a meta description be? +
Google displays meta descriptions up to 160 characters on desktop and around 120 characters on mobile. The ideal length is 120–155 characters — long enough to convey value, short enough to avoid truncation. Our generator targets this range and shows you a character count for each option.
Does Google always use the meta description I write? +
Not always. Google may choose to display a snippet of your page content instead of your meta description if it believes the content is more relevant to the search query. This happens in roughly 30% of searches. However, a well-written meta description with your target keyword is still best practice and increases the chances Google uses it.
Should I include keywords in meta descriptions? +
Yes. Google bolds keywords in the meta description that match the user's search query, making your result stand out visually. Include your primary keyword naturally in the description. Don't keyword-stuff — write for the human reader first, search engines second.
