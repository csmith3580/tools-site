When to Use Each Case Format

🔠
UPPERCASE

Used for acronyms, headers requiring strong emphasis, legal documents, and constants in programming. Example: NASA, HTML, MAX_VALUE.

🔡
lowercase

Standard for body text, email addresses, URLs, CSS class names, and most programming variable names in Python and Ruby.

📝
Title Case

Used for article headlines, book titles, movie titles, and product names. Every major word is capitalized.

💻
camelCase

Standard naming convention in JavaScript, Java, and TypeScript for variables and functions. Example: myVariableName, getUserData.

🐍
snake_case

Standard in Python, Ruby, and SQL for variable names, function names, and database column names. Example: user_first_name.

🔗
kebab-case

Standard for CSS class names, HTML attributes, and URL slugs. Search engines treat hyphens as word separators, making this ideal for SEO-friendly URLs.

Frequently asked questions

What is a case converter? +
A case converter transforms text between different letter case formats — UPPERCASE, lowercase, Title Case, and programming formats like camelCase or snake_case. Writers use it to fix capitalization, while developers use it to format variable names and code identifiers.
What is the difference between camelCase and PascalCase? +
In camelCase, the first word is lowercase and subsequent words start with a capital letter — for example: myVariableName. In PascalCase (also called UpperCamelCase), every word starts with a capital letter — for example: MyVariableName. camelCase is common in JavaScript and Java; PascalCase is commonly used in C#, TypeScript classes, and React components.
What is snake_case used for? +
snake_case uses underscores between words with all letters lowercase — for example: my_variable_name. It is the standard naming convention in Python, Ruby, and SQL. It's also commonly used for file names and URL slugs because underscores are treated as word separators by search engines.
What is kebab-case? +
kebab-case uses hyphens between words with all letters lowercase — for example: my-variable-name. It gets its name because the hyphens look like kebab skewers. It's the standard format for CSS class names, HTML attributes, and URL slugs. Search engines treat hyphens as word separators, making kebab-case ideal for SEO-friendly URLs.
